# RESOLVE — User Guide

## 1. Initial Setup (Settings Tab)
1. Open **Settings -> Recovery Code** and generate or enter a 16-digit (or optional 32-digit) numeric recovery code. Record it safely.
2. Check **Device Management**. Genuine app restriction requires Device Owner provisioning (tap **View Setup Guide** for the exact ADB command).
3. On Android 12+, enable **Alarms & Reminders** if prompted; on Android 13+, allow **Notifications**.

## 2. Selecting Allowed Apps & Durations
- Tap the large `HH : MM` readout to type exact hours and minutes, or drag the independent **Hours** and **Minutes** wheels, or tap a quick preset.
- Tap **Allowed Applications** to search and select which apps remain accessible during Lock Mode.

## 3. Modes
- **Instant Lock:** Starts Lock Mode immediately.
- **Delayed Lock:** Lets you use the phone normally during the **Free Use Window**, then automatically enters Lock Mode for the **Lock Duration**.
- **Schedule Lock:** Starts Lock Mode automatically at a One-Time, Daily, or Weekly time.

## 4. Ending a Session Early
On the Lock Screen, tap the discreet key icon in the bottom dock and enter your 16-digit (or 32-digit) recovery code.
