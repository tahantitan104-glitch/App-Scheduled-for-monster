Resolve — Installable Debug APK
================================
File: app-debug.apk
Package ID: com.resolve.focus
Version: 1.0.8 (versionCode 9)
Min SDK: Android 5.1.1 (API 22) — backward-compatible with tablets & phones, refined condensed Landscape Flip Clock typography & dynamic Leading Zero centering, server-clock-calibrated Multi-Device Lock Sync (Instant, Delayed & Scheduled locks with full preference parity across API 22 REST & API 23+ Firestore SDK), background ResolveSyncService keep-alive, REST Google Account & Photo Sync on API 22, external/SD storage supported

Install Instructions:
1. Download / export the project ZIP (or download app-debug.apk from this folder).
2. Transfer app-debug.apk to your Android phone or tablet (Android 5.1.1+) and tap it to install (allow "Install unknown apps" / "Unknown sources" if prompted).
3. Open Resolve -> More/Settings tab -> Sign In with Google for Sync (works on Android 5.1.1 via Play Services + REST sync, and Android 6.0+ via CredentialManager), ensure Focus Guard & Recovery Code are configured, and keep "Sync Lock Across Devices" enabled on both devices.
