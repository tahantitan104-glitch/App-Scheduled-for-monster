Resolve — Installable Debug APK
================================
File: app-debug.apk
Package ID: com.resolve.focus
Version: 1.0.1 (versionCode 2)
Min SDK: Android 6.0 (API 23)

Install Instructions:
1. Download / export the project ZIP (or download app-debug.apk from this folder).
2. Transfer app-debug.apk to your Android phone and tap it to install (allow "Install unknown apps" if prompted).
3. Open Resolve -> Settings tab -> set a Recovery Code and enable "Resolve Focus Guard" in Accessibility Settings.
