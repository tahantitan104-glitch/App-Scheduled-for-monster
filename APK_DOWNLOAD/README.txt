Resolve — Installable Debug APK
================================
File: app-debug.apk
Package ID: com.resolve.focus
Version: 1.0.8 (versionCode 9)
Min SDK: Android 5.1.1 (API 22) — backward-compatible with tablets & phones, Flip Clock Weather (°C/°F + auto-detect + offline disk cache), Wakeful faster Multi-Device Lock Sync with persistent offline outbox (API 22 REST & API 23+ Firestore SDK), Local VPN DNS Blocker (Short-Video/Social/Adult & custom domains), and dedicated Flip Clock White Noise Studio (44.1 kHz stereo real-time White Noise, Soft Rain, Bonfire, Forest Wind, River Waves, Ocean Waves, Thunderstorm, Deep Brown, Warm Hum & Lo-Fi Pad with background playback & sleep fade-out)

Install Instructions:
1. Download / export the project ZIP (or download the updated app-debug.apk from APK_DOWNLOAD/ or app/build/outputs/apk/debug/).
2. Transfer app-debug.apk to your Android phone or tablet (Android 5.1.1+) and tap it to install (allow "Install unknown apps" / "Unknown sources" if prompted).
3. Open Resolve -> More/Settings tab -> Sign In with Google for Sync (works on Android 5.1.1 via Play Services + REST sync, and Android 6.0+ via CredentialManager), configure Focus Guard / Recovery Code / Local VPN DNS Blocker, and keep "Sync Lock Across Devices" enabled on both devices.
